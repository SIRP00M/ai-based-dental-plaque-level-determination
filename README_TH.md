# AI-Based Dental Plaque Level Determination

[English](README.md) | **ภาษาไทย**

ระบบวิเคราะห์ระดับคราบจุลินทรีย์บนผิวฟันด้วย AI สำหรับผู้พิการทางสายตา พัฒนาระหว่างการฝึกงาน ณ **บริษัท พีเอสยู ดอลฟินส์ จำกัด (PSU-Dolphins Co., Ltd.)** ร่วมกับ **คณะทันตแพทยศาสตร์ มหาวิทยาลัยสงขลานครินทร์** และ **คณะทันตแพทยศาสตร์ มหาวิทยาลัยมหิดล**

โปรเจกต์นี้ต่อยอดจากการแยกบริเวณฟันด้วย Mask R-CNN โดยเพิ่มระบบตรวจหาคราบจุลินทรีย์ การให้คะแนน PHP/QHPI การสร้างภาพสรุปผลแบบ Dashboard และการสร้างคำแนะนำการแปรงฟัน

> โปรเจกต์นี้จัดทำเพื่อการวิจัยและการศึกษา ผลลัพธ์จากระบบควรได้รับการตรวจสอบและยืนยันโดยทันตแพทย์หรือบุคลากรทางทันตกรรมที่มีคุณสมบัติเหมาะสมก่อนนำไปใช้ทางคลินิก

---

## ภาพรวมระบบ

ระบบใช้วิเคราะห์ภาพถ่ายฟันหลังการย้อมคราบจุลินทรีย์ (plaque-disclosing treatment) เพื่อประมาณการสะสมของคราบจุลินทรีย์บริเวณฟันหน้าบน

ความสามารถของระบบในปัจจุบัน:

- แยกบริเวณฟันด้วย Mask R-CNN
- ระบุตำแหน่งฟันหน้าบนอัตโนมัติตามระบบ FDI
- ตรวจหาคราบจุลินทรีย์จากสีของสารย้อมคราบ
- คำนวณคะแนน PHP (Patient Hygiene Performance)
- คำนวณคะแนน QHPI (Quigley-Hein Plaque Index)
- สร้างภาพแสดงผลรายซี่
- สร้าง Dashboard สรุปผลรายเคส
- สร้างคำแนะนำการแปรงฟัน

---

## ฟันที่ระบบรองรับ

ระบบเวอร์ชันปัจจุบันมุ่งเน้นการวิเคราะห์ฟันหน้าบนจำนวน 6 ซี่:

| รหัส FDI | ตำแหน่งฟัน |
| --- | --- |
| 13 | ฟันเขี้ยวบนขวา |
| 12 | ฟันตัดข้างบนขวา |
| 11 | ฟันตัดกลางบนขวา |
| 21 | ฟันตัดกลางบนซ้าย |
| 22 | ฟันตัดข้างบนซ้าย |
| 23 | ฟันเขี้ยวบนซ้าย |

## ลำดับการทำงานของระบบ

```text
ภาพถ่ายฟัน
        ↓
แยกบริเวณฟันด้วย Mask R-CNN
        ↓
ระบุหมายเลขฟัน FDI อัตโนมัติ
        ↓
ตรวจหาคราบจุลินทรีย์
        ↓
คำนวณคะแนน PHP และ QHPI
        ↓
สร้างภาพ Visualization และ Summary Dashboard
        ↓
สร้างคำแนะนำการแปรงฟัน
```

Pipeline หลักอัตโนมัติแบ่งเป็น 3 ขั้นตอน:

```text
Step 1: Run_Model_1Class.py
        → แยกบริเวณฟันและบันทึกภาพฟันรายซี่

Step 2: plaque_detection.py
        → ตรวจคราบ คำนวณ PHP/QHPI และสร้าง report/JSON

Step 3: plaque_summary.py
        → สร้างภาพ Dashboard สรุปผลแบบ clinical-style
```

## ความต้องการของระบบ

โปรเจกต์นี้พัฒนาด้วย:

- Python 3.7.16
- Anaconda / Conda environment
- Mask R-CNN
- OpenCV
- NumPy
- Pillow

ตัวอย่างการสร้าง environment เบื้องต้น:

```bash
conda create -n MaskRcnn python=3.7.16
conda activate MaskRcnn

pip install numpy pillow opencv-python
```

ต้องติดตั้ง Mask R-CNN และ dependency ด้าน deep learning ที่สอดคล้องกับเวอร์ชันของโมเดลที่ใช้เพิ่มเติม

> Environment ที่ใช้พัฒนาเดิมมีชื่อว่า `MaskRcnn`

## การรัน Pipeline แบบเต็ม

เปิด terminal ที่ root ของ repository แล้วรัน:

```bash
python master_run_pipeline.py
```

ระบบจะทำงานตามลำดับ:

```text
AI Tooth Segmentation
→ Plaque Detection และ PHP/QHPI Analysis
→ Summary Dashboard Generation
```

หากยังไม่มีผลลัพธ์การแยกฟันเดิม ระบบจะรันครบทั้ง 3 ขั้นตอนโดยอัตโนมัติ

## โหมดการรันเพิ่มเติม

### บังคับให้ AI แยกฟันใหม่

```bash
python master_run_pipeline.py --force-ai
```

ใช้เมื่อเปลี่ยนรูป input หรือเมื่อต้องการสร้างผล segmentation ใหม่ทั้งหมด

### รันเฉพาะการตรวจคราบและ Dashboard

```bash
python master_run_pipeline.py --detection-only
```

ใช้เมื่อมีผลการแยกฟันอยู่แล้ว และต้องการรันวิเคราะห์คราบพร้อมสร้าง Dashboard ใหม่

### รันเฉพาะการสร้าง Dashboard

```bash
python master_run_pipeline.py --summary-only
```

ใช้เมื่อมี `case_results.json` หรือผลการวิเคราะห์คราบอยู่แล้ว และต้องการสร้างภาพ Dashboard ใหม่เท่านั้น

> สำหรับการใช้งานจริงเมื่อถ่ายภาพฟันใหม่ ควรรัน pipeline แบบเต็มหรือใช้ `--force-ai` เนื่องจากรูปใหม่จำเป็นต้องได้รับการแยกฟันใหม่

## การวิเคราะห์ PHP และ QHPI

### PHP Scoring

ระบบแบ่งพื้นผิวฟันแต่ละซี่ออกเป็น zone แล้วตรวจว่ามีคราบอยู่ในแต่ละ zone หรือไม่

สำหรับฟันทั่วไป zone ที่ตรวจประกอบด้วย:

```text
M = Mesial    / ด้านประชิดกลาง
I = Incisal   / ขอบตัด
C = Center    / กลางผิวฟัน
G = Gingival  / ใกล้ขอบเหงือก
D = Distal    / ด้านประชิดไกลกลาง
```

สำหรับฟันเขี้ยวที่มองจากภาพด้านหน้า อาจเห็นพื้นผิวด้านข้างไม่ครบถ้วน ระบบจึงรองรับการปรับจำนวน zone สำหรับฟันหมายเลข 13 และ 23

### QHPI Scoring

ระบบประมาณคะแนน QHPI จากการกระจายตัวของคราบบริเวณใกล้ขอบเหงือก ความลึกของคราบ และพื้นที่ครอบคลุมบนผิวฟัน

การคำนวณ QHPI ในระบบปัจจุบันเป็นการประมาณเชิงคอมพิวเตอร์สำหรับต้นแบบงานวิจัย และควรนำไปเปรียบเทียบกับคะแนนจากทันตแพทย์ก่อนนำไปใช้งานจริง
